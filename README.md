## 349 元买到的东西，和它不管的事

Scrivener 的核心是把一部长文拆成可以随意重排的块。左侧的 Binder 是一棵树，每一章每一节甚至每个场景都能拆成独立节点，写的时候一次只面对一小块，改结构的时候拖着节点换位置，不用在几万字里剪切粘贴。软木板视图把这些节点摊成卡片，适合理时间线和场景顺序。参考资料可以塞进同一个项目里，照片、PDF、网页笔记和采访转录都放得进去，写某一段时旁边就能翻。

写作界面有一个打字机模式，把当前这段顶到屏幕中间，其余部分压暗，用来对付盯着光标发呆这件事。自动保存和自动备份可以自己设位置、间隔和保留份数，掉电和崩溃不至于把当天进度清空。

它不管的事也得说。Scrivener 不生成文字，一行都不会替你写。参考文献的著录格式也不归它管，那还是得靠专门的文献管理工具。没有 Android 版，也没有网页版，换到手机上只能靠 iOS 版或者导出文件。编译（Compile）是它最需要花时间的一块，把项目导出成 Word、PDF 或 EPUB 时选项很多，第一次用大概率要试几遍才顺眼。

## 谁该买，谁别买
